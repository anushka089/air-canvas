# Air Canvas 

Air Canvas is a computer vision project that allows you to draw in the air using your hand movements.

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

## Features

- Real-time hand detection
- Tracks finger movement
- Draws on a virtual canvas
- Uses the webcam for input
